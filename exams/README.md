# 单元练习卷（入库）

来源：四年级上册 U1 / U2 校内练习卷。扫描件在 `source/`，清晰排版卷在 Word / PDF。

## 文件

| 文件 | 说明 |
|------|------|
| `U1_第一单元练习.docx` / `U1_Unit1_Practice.docx` | U1 清晰排版 Word（十大题结构同原卷） |
| `U2_第二单元练习.docx` / `U2_Unit2_Practice.docx` | U2 清晰排版 Word |
| `U1_Unit1_Practice.pdf` / `U2_Unit2_Practice.pdf` | 同内容 PDF |
| `source/u1-*.png` `source/u2-*.png` | 原卷扫描对照 |
| `_gen_unit_papers.py` | 重新生成 Word |

## 题型 ↔ Records「迷你卷」

| 试卷题型 | Records 迷你卷 |
|----------|----------------|
| 三·听句子选答语 | 迷你卷·听选答语 |
| 四·听短文判断 | 迷你卷·听短文判断 |
| 五·画线音 √× | 迷你卷·画线音（U1/U2 卷面词对） |
| 六·同类词 / 异类词 | 迷你卷·词分类 / 异类词 |
| 七·看图选句 | 迷你卷·看图选句（文字描述图意） |
| 八·问句选答语 | 迷你卷·问句答语 |
| 九·补全对话 | 迷你卷·补全对话 |
| 十·阅读 + 仿写 | 迷你卷·阅读 + 仿写 |
